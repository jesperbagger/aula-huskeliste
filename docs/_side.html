Aula-huskeliste
Sådan virker det Opsætning Privatliv GitHub

Vid hver aften, hvad børnene skal huske i morgen.

Aula-huskeliste læser beskeder, opslag og kalender i Aula og sender dig en kort mail kl. 19.30. Nye arrangementer lander i Google-kalenderen, og skriver læreren i kontaktbogen, ved du det, før du henter.

Sæt det op Se koden på GitHub

Et gratis fritidsprojekt fra en forælder. Det er ikke lavet af eller godkendt af Aula, KL, STIL eller Netcompany.

Sådan virker det

Du får din egen lille server, som taler med Aula på dine vegne. To gange om dagen læser Claude det nye og skriver en huskeliste med kun det, der kræver noget af dig. Er der ikke noget, hører du ingenting.

Opsætning i fem trin

Vælg din computer, så viser vejledningen de rigtige kommandoer.

1

Opret en gratis server hos Oracle ca. 20 min

  1. Opret en konto på oracle.com/cloud/free. Vælg en hjemmeregion i nærheden, fx Sweden Central eller Germany Central. Den kan ikke ændres senere.
  2. Gå til Compute → Instances → Create instance. Vælg image Canonical Ubuntu 24.04 og shape VM.Standard.E2.1.Micro (mærket Always Free).
  3. Under SSH keys: vælg Generate a key pair for me og tryk Save private key. Gem filen godt, for uden den kan du ikke komme ind på serveren.
  4. Skriv maskinens offentlige IP-adresse ned.
  5. Åbn port 80 og 443 i netværkets Security List (Source 0.0.0.0/0, TCP).

Vejledning med alle klik og løsninger på typiske problemer: docs/1-oracle-server.md

2

Installer serveren ca. 5 min

Åbn PowerShell og log ind på serveren. Ret filnavnet og IP-adressen til dine egne:

Åbn Terminal og log ind på serveren. Ret filnavnet og IP-adressen til dine egne:

I Terminal på din Mac

Svar yes første gang. Når du står på serveren, kører du denne ene kommando:

På serveren
curl -fsSL https://raw.githubusercontent.com/jesperbagger/aula-huskeliste/main/scripts/install-server.sh | bash

Til sidst viser scriptet tre oplysninger: Connector-URL, Header-navn og Header-værdi. Gem dem i din password manager. Du kan altid se dem igen med kommandoen aula-connector.

3

Log ind med MitID ca. 5 min

Aula tillader kun MitID-login fra almindelige hjemmeforbindelser. Du logger derfor ind fra din egen computer, og scriptet flytter login'et sikkert over på serveren bagefter.

I PowerShell på din computer
irm https://raw.githubusercontent.com/jesperbagger/aula-huskeliste/main/scripts/login-windows.ps1 | iex
I Terminal på din Mac
bash -c "$(curl -fsSL https://raw.githubusercontent.com/jesperbagger/aula-huskeliste/main/scripts/login-mac.sh)"

Scriptet spørger om serverens IP-adresse og din SSH-nøgle. Derefter beder det om dit MitID-brugernavn ("MitID username") og viser en QR-kode, som du scanner med MitID-appen. Kopien af login'et på din computer slettes automatisk bagefter.

Du kører det samme script igen, hvis du en dag får mailen "Aula-automation: kræver handling". Det betyder, at login'et er udløbet.
4

Gå til claude.ai → Indstillinger → Connectors → Add custom connector og udfyld:

Vælg X-API-Key i listen og indsæt din Header-værdi. Findes den ikke, så vælg Authorization og skriv Bearer foran nøglen.
Skriv ikke dit eget header-navn. Custom header-navne kræver godkendelse fra Anthropic.

Tryk Add. Du skal nu se en liste med Aula-værktøjer. Sæt dem til Always allow i dropdown-menuen ud for "Other tools". De kan kun læse, ikke sende eller ændre noget i Aula.

5

Opret de planlagte opgaver ca. 5 min

  1. Kopiér opsætningsprompten med knappen herunder.
  2. Start en ny opgave i Claude Cowork og indsæt teksten.
  3. Claude finder dine børn i Aula, spørger om mailadresser og kalender og opretter opgaverne kl. 15.00 og 19.30.
  4. Slå Automatically approve til på opgaverne, hvis Claude beder om det.
  5. Sig ja til en testkørsel, og tjek din mail.

Privatliv og ansvar

Sådan passes der på dine data

  • Dit Aula-login ligger krypteret på din egen server. Udvikleren af projektet har ingen adgang.
  • Serveren kan kun nås med en hemmelig adresse og en hemmelig nøgle.
  • Kun læseadgang: der kan ikke sendes beskeder eller ændres noget i Aula.
  • Tråde, som Aula har markeret som følsomme, åbnes aldrig.
  • Den fælles mail genfortæller aldrig personlige samtaler, og kontaktbogen går kun til dig.

Vigtigt at vide

  • Uofficielt: aula-mcp bruger Aulas interne API. Aula kan ændre det, så løsningen holder op med at virke i en periode.
  • Claude læser indholdet af beskeder og opslag, når opgaverne kører. Det er dit valg, om du er tryg ved det.
  • Ingen garanti: tjek altid Aula selv ved vigtige ting.
